1 · What can an eavesdropper see?

The same login is sent to the HTTP server (:8080) and the HTTPS server (:4433). A relay in the middle records every byte, like Wireshark would.

Press “Run experiment”.

2 · Who trusts which certificate?

Rows: the certificate the server presents. Columns: how the client is set up.

Press “Run certificate check”.

3 · Try it yourself

  • curl -k -X POST https://localhost:4433/login -H "Content-Type: application/json" -d '{"username":"sujal"}'
  • curl --cacert certs/server.crt https://localhost:4433/api/whoami
  • curl -i http://localhost:8082/anything  (redirects to HTTPS)
  • openssl s_client -connect localhost:4433 -servername localhost
  • openssl s_client -connect localhost:4433 -tls1_1 -cipher 'DEFAULT:@SECLEVEL=0'  (server refuses TLS 1.1)
  • Wireshark on the loopback interface, filters http and tls - see docs/wireshark-guide.md
